F-01

Tokens CSS

Las variables CSS raíz del sistema. Todo color, tamaño y espaciado del SIAF-PJEV vive aquí.

Foundations No genera TSX · Es el archivo _pjev-tokens.css
Paso 1 — bloquea todo
1 Descripción

Los tokens son las decisiones de diseño más importantes del sistema. Cada variable define un valor único que se usa en todos los componentes. Cambiar --pjev-verde-oscuro en este archivo actualiza automáticamente el color de todos los botones, headers y barras del sistema.

Este archivo se extrae del globals.css actual del proyecto y se amplía con los tokens que faltan (éxito, error, advertencia, información).

3 Tokens / Propiedades
Token / Prop Tipo Valor Descripción
--pjev-verde-oscuro color #183125 Color primario institucional. Topbar, botones primary, texto de título.
--pjev-verde-medio color #254a37 Hover state del botón primary.
--pjev-verde-claro color #33614a Active state del botón primary.
--pjev-dorado color #DEAC50 Logo, subrayado de sistema activo en topbar.
--pjev-rojo-vino color #5e111a Acciones destructivas, badges de cancelado/rechazado.
--pjev-crema color #F5F0E8 Fondo general de página, hover de sidebar, filas alternas.
--pjev-blanco color #FFFFFF Fondo de cards, sidebar, inputs, modales.
--pjev-texto color #1A1A1A Texto principal.
--pjev-texto-muted color #5A5A5A Texto secundario, labels, hints.
--pjev-borde color #D4C9B5 Bordes de cards, inputs, tablas.

7 Patrones deprecados en el sistema actual
⚠
Toda pantalla con COLORS = {...} — Objeto de colores local
Eliminar y usar tokens globales
⚠
transferencias/page.tsx — COLORS.green = '#285847'
Reemplazar con var(--pjev-verde-oscuro)
⚠
roles/page.tsx — color: '#1B3A2D' hardcodeado
Reemplazar con var(--pjev-verde-oscuro)
