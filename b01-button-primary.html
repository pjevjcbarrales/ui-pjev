Button — Primary

Documentación del elemento B-01.

Base Elements SiafButton.tsx
Nuevo componente
1 Descripción

El botón principal del sistema. Se utiliza para la acción principal y más importante de una pantalla, como "Guardar", "Registrar" o "Confirmar".

⚠
Regla de oro: Nunca debe haber más de un botón primario visible a la vez en una misma vista o modal.

4 Código de implementación
import React from 'react'
import { clsx, type ClassValue } from 'clsx'

interface SiafButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant: 'primary' | 'secondary' | 'danger' | 'ghost';
  size?: 'sm' | 'md' | 'lg';
  loading?: boolean;
  icon?: React.ReactNode;
  iconOnly?: boolean;
}

export function SiafButton({ 
  variant, size = 'md', loading, icon, iconOnly, 
  className, children, disabled, ...props 
}: SiafButtonProps) {
  const baseClass = 'siaf-btn';
  const variantClass = `siaf-btn-${variant}`;
  const sizeClass = size !== 'md' ? `siaf-btn-${size}` : '';
  
  return (
    <button 
      className={clsx(baseClass, variantClass, sizeClass, loading && 'siaf-btn-loading', iconOnly && 'siaf-btn-icon-only', className)}
      disabled={disabled || loading}
      {...props}
    >
      {loading && <div className="siaf-spinner" />}
      {!loading && icon && icon}
      {!iconOnly && children}
    </button>
  )
}

No usar estilos inline (style={{...}}) ni colores hexadecimales hardcodeados en los componentes.
